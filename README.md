The Shape Discovery Workbook is a practical tool designed to help users identify, analyze, and understand patterns, relationships, and structures within data, processes, or visual frameworks. Whether used for business analysis, strategic planning, education, problem-solving, or research, the workbook provides a structured approach to discovering meaningful insights and recognizing recurring "shapes" or patterns that drive outcomes.

This repository contains the workbook, supporting resources, and documentation needed to effectively use and customize the Shape Discovery methodology.
